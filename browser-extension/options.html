Tickets Assignment Tracker Notifier

Pick your name so this extension knows which ticket assignments are yours. You'll get a notification whenever a new ticket is assigned to you — red if the initial response hasn't been sent yet, green if it has.

Alert sound

Plays when a new ticket is assigned to you, and when the Zendesk queue has unassigned tickets waiting.

Test plays at the volume set here, so you can find a level that carries without startling you.

Your own sounds

Upload a short audio file to use instead of the built-in tones. It is saved in this browser only — nothing is sent anywhere, and it doesn't change what anyone else hears.
